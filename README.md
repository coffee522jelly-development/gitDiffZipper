# Git差分ZIP作成ツール (gitDiffZipper)

Gitリポジトリから指定したコミットの変更ファイルを抽出し、ZIPファイルとして出力するWindows向けデスクトップアプリケーションです。

## 主な機能

- **差分抽出**: 指定したコミット（最新からN個前）や範囲（HEAD~MからHEAD~N）の変更ファイルを自動抽出。
- **コミット履歴表示**: 直近20件のコミット履歴を確認し、差分の開始点・終了点をワンクリックで設定可能。
- **ZIP生成**: フォルダ構造を維持したままZIPアーカイブを作成。内部のパスはクロスプラットフォーム対応（スラッシュ区切り）。
- **readme.txt自動生成**: コミットハッシュ、メッセージ、日時、ファイル一覧を含むメタデータをZIP内に同梱。
- **manifest.txt生成**: ZIPと同じ出力先に、どのコミットの変更かを示すIDとファイル一覧を記述したマニフェストファイルを出力。
- **除外フィルタ**: 特定の拡張子やファイル名パターンを指定して除外可能。設定は保存されます。
- **リモート更新**: アプリ内から `git fetch` を実行し、GitHub等の最新情報を同期。
- **設定保存**: Git実行ファイルのパス、除外フィルタ、対象範囲の設定を自動で保持。
- **堅牢なパス処理**: Windowsで「パスとしてコピー」した際の引用符（"）などを自動除去。出力先フォルダがない場合は自動作成。
- **ミニマルデザイン**: デスクトップで邪魔にならない極限まで高密度・省スペースなUI（左ペインのコミット履歴を画面幅の約27%に縮小し、全体の余白を最小化）。

## 動作要件

- Windows 10 / 11
- Git for Windows がインストールされていること（PATH設定は不要です）

## 使い方

1. **Git実行ファイルの設定**: `git.exe` の場所を指定します（初回のみ）。
2. **リポジトリの選択**: 対象となるGitリポジトリのフォルダを選択します。
3. **コミットの指定**:
   - 履歴一覧から「始」「終」ボタンを押して範囲を指定するか、手動で数値を入力します。
   - `0` が最新（HEAD）です。
4. **（任意）リモート更新**: GitHub等の最新コミットを対象にしたい場合は「↻」ボタンを押して情報を更新します。
5. **（任意）除外フィルタ**: 除外したいパターン（例: `.pdf, .zip`）を入力します。
6. **出力先の指定**: 保存するZIPファイルの名前と場所を指定します。
7. **ZIP作成**: ボタンを押すと処理が開始されます。

## 開発者向け情報

### 技術スタック
- **Backend**: Rust / Tauri v2
- **Frontend**: Svelte 5 (Runes) / TypeScript
- **Styling**: Tailwind CSS

### ビルド方法

```bash
# 依存関係のインストール
npm install

# 開発モードの起動
npm run dev

# インストーラーのビルド (msi, nsis)
npm run tauri build
```
